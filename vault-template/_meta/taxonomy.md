# Tag Taxonomy

*Controlled tag vocabulary for this vault. Maintained by the `tag-taxonomy` skill — new tags are proposed here before wide use. Max 5 domain/type tags per page; `visibility/` system tags don't count toward the limit.*

## Domain Tags

*Seeded by the template's demo pages — prune or extend freely.*

- `knowledge-management` — how knowledge is captured, structured, and retrieved
- `agentic-systems` — agents, their rules, and their coordination

## Type Tags

- `tools` — a concrete tool, app, or framework
- `wiki-ops` — operations on this vault itself
- `meta` — pages about the vault system rather than world knowledge

## System Tags

- `visibility/public` — visible in all query modes (default when untagged)
- `visibility/internal` — excluded in filtered/public-only queries
- `visibility/pii` — sensitive; excluded in filtered queries
