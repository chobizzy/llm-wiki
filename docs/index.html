02 · Architecture

Three Layers. Compiled once.

Most "chat with notes" tools query at question time. llm-wiki compiles knowledge once when a source arrives into linked markdown pages you read in Obsidian.

LAYER 01

Sources · Immutable Truth

PDFs, articles, papers, chat exports, screenshots. Immutable ground truth stored in _inbox/. Agents read them and never modify them.

LAYER 02

The Wiki · Build Artifact

Small linked pages with frontmatter and inline provenance. The compiled artifact you browse, search, edit, and diff in Obsidian.

LAYER 03

The Schema · Governance

AGENTS.md, 32 skills, and a CLI gate. Enforces written law to keep agents honest across sessions and models.

03 · Deterministic Gate

The DONE Contract

Agents are explicitly forbidden from grading their own homework. An operation is complete only when all six criteria hold, followed by a deterministic doctor & lint check.

✓ 01

Full Frontmatter

Pages written with complete YAML schema and wikilinks to related pages.

✓ 02

Manifest Registry

.manifest.json updated for every source file ingested.

✓ 03

Operation Log

log.md appended with ISO-8601Z timestamped agent action entry.

✓ 04

Hot List Summary

hot.md refreshed with a concise update of modified concepts.

✓ 05

Index Reconciled

index.md updated so every page is referenced exactly once.

✓ 06

Deterministic Gate

llm-wiki doctor passes and llm-wiki lint reports 0 fail findings.

04 · Paradigm Comparison

Compared to RAG

Both process your documents. They differ in when the work happens and what artifact is produced.

Property Typical RAG llm-wiki
Execution Phase Query time (every question) Ingest time (compiled once)
Storage Format Opaque Vector DB embeddings Plain Markdown files in Git
Duplicates Near-duplicate chunks pile up One concept, one page (merged)
Uncertainty Claim Swallowed in prose Marked ^[inferred] explicitly
Verification Gate Model self-assessment Deterministic CLI doctor gate

06 · Command Line

Zero-Dependency Python CLI

A ~2,600 line standard-library CLI handling deterministic operations so you never rely on LLMs for system state.

Command Purpose
llm-wiki setup --vault PATH Links skills into detected agent directories (~/.claude, ~/.hermes)
llm-wiki doctor [--strict] Health-checks config, vault shape, and installed agent skills
llm-wiki lint [VAULT] --json Audits frontmatter, broken wikilinks, duplicate titles, and orphans
llm-wiki graph-analyse VAULT Analyzes graph topology for hub nodes, communities, and bridges
llm-wiki ast-extract PATH Extracts code AST structures (classes, functions, imports) without LLM calls
llm-wiki pdf-extract PDF Extracts text layer and OCR from PDFs with PyMuPDF
07 · Governance

Laws, Not Tips

Prompt instructions vanish across sessions. A file in the repo persists. AGENTS.md defines written law for every skill.

LAW 01
Never delete a wiki page. Supersede it: set lifecycle: archived and superseded_by:.
LAW 02
Never modify anything in _inbox/. Layer 1 sources are immutable ground truth.
LAW 03
Never present a synthesized claim as extracted. Mark it ^[inferred].
LAW 04
Never create duplicate pages for existing concepts. One concept, one page — merge.
LAW 05
Never set lifecycle above draft on writes. reviewed / verified are human-only.
